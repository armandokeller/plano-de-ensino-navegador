# Script para habilitar preenchimento automático do plano de ensino
O script pode ser utilizado diretamente no navegador, sendo colado no console (ferramentas de desenvolvedor).
Foi testado no Microsoft Edge mas deve funcionar em qualquer navegador.

# Forma de uso

1 -  Tenha o seu plano de ensino em uma planilha do Excel, dividido em duas colunas, uma com a data no formato dd/mm e outra com o conteúdo previsto.

2 - No navegador, vá até a página de preenchimento do plano de aula, selecione a etapa e as datas (deve aparecer 38 itens).

3 - Abra as ferramentas de desenvolvedor e vá em console (No Edge o atalho é Ctrl+shift+i)

4 - Cole o conteúdo do arquivo [plano_de_ensino.js](./plano_de_ensino.js) no console e aperte Enter.

5 - Copie as duas colunas da planilha do Excel (19 aulas), e cole na janela que foi aberta no navegador, em seguida clique em OK.


Obs: Eu já fiz uma extensão (complemento) para o Edge para facilitar o processo, mas ainda está em processo de análise pela Microsoft.
